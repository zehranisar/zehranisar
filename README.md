### 🚦 Smart Traffic Signal Control · *Reinforcement Learning*

> **Q-learning, DQN and PPO agents learn to run a four-way intersection**, benchmarked against fixed-timer and longest-queue controllers on 30 unseen traffic scenarios per level.

| Traffic | Fixed timer (30 s) | **DQN** | Queue reduction |
|:---:|:---:|:---:|:---:|
| Normal | 25.2 cars | **5.1 cars** | **−80%** |
| Rush | 75.6 cars | **31.9 cars** | **−58%** |

*Average queue length in a custom Gymnasium simulation. The simple longest-queue rule still wins in light traffic, and the report covers the limits honestly. Includes a live side-by-side demo with a FastAPI backend and React frontend.*
